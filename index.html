Features Everything currently available in the project canvas

Canvas & navigation

  • Drag empty canvas space to pan around the workspace.
  • Scroll to zoom in and out.
  • Use the zoom controls for +, −, and 1:1 reset.
  • Magnetic node snapping and alignment guides can be toggled with Snapping.

Nodes & objects

  • Add Text, Media, and File nodes from the top toolbar.
  • Double-click empty canvas space to quickly add a text node.
  • Right-click empty canvas space for the add menu.
  • Drag nodes and images anywhere on the workspace.
  • Press Delete or Backspace to remove the selected object.

Connections

  • Connect nodes from left, right, top, or bottom connection dots.
  • Choose connection-line color from the toolbar swatches.
  • Connection dots appear on hover/selection and stay visible when connected.
  • Right-click a connection dot to remove all lines attached to that dot.
  • Double-click a connection line to delete it.

Media

  • Use + Media to add images or videos directly to the canvas.
  • Paste screenshots/copied images directly with Ctrl+V.
  • Videos play directly on the node with a minimal custom Play/Pause control only.
  • Audio files—including MP3, M4A/M4B, AAC, WAV, FLAC, OGG and Opus—can be dropped or added with Media and use a compact Play/Pause, timestamp, and seek/progress bar.
  • Audio nodes show the source filename above the playback controls.
  • Large binary media/assets are stored separately from the workflow structure, avoiding Base64-heavy autosaves.
  • Project files use virtual paths inside each node. Renaming/moving a virtual path never changes the original file on disk.
  • Code edits are node-local working copies and only persist when Save/Ctrl+S is used. Real-time preview changes are discarded when closed unless saved.
  • Double-click a video to open the large media viewer; the large viewer includes a full-screen button.
  • Resize images from edge or corner handles.
  • Corner resize handles preserve image aspect ratio.
  • Right-click an image to delete it, reset its size, or toggle rounded corners.
  • Double-click an image for a full-window preview; click the backdrop, ×, or press Esc to close.
  • Full-size image preview supports wheel zoom, +/−/1:1 controls, double-click zoom, and drag-to-pan while zoomed.

Files

  • Multi-file project nodes: select several files at once or use Add folder to preserve nested paths.
  • Drag an entire folder directly onto a File node or empty canvas to import every file and subfolder while preserving its directory structure.
  • Drop folders directly into the open Files manager or editor Files window to append them to that project node.
  • Dropping a whole folder onto empty canvas automatically creates a new Project File node.
  • Dropping a ZIP file into a Project/File node extracts the ZIP and imports its internal files/folders instead of storing only the ZIP filename.
  • Choose the active uploaded file directly from the node using the file dropdown; Edit/Preview follows that selection.
  • HTML previews resolve sibling CSS, JavaScript, images, fonts, media, and other relative project files stored in the same node.
  • Folder upload is recommended when the web project uses subfolders such as css/, js/, or images/.
  • Use the Files button inside a project node to browse every uploaded file and edit any text/code file, not only the main HTML file.
  • Code/text files expose an Edit button.
  • HTML/HTM and SVG files expose a Preview button.
  • Image files such as PNG, JPG/JPEG, GIF, WEBP, BMP, AVIF, ICO, and SVG can be previewed directly as images.
  • HTML preview includes a bottom Real-time editor drawer that updates the preview while you type.
  • Use Ctrl+S inside the editor to save code changes.

Archives

  • ZIP, RAR, 7Z, TAR, GZ and other common archive/container files expose View contents.
  • Archive contents open inside the project and show internal paths and file sizes.
  • ZIP-based formats such as EPUB, CBZ, JAR, APK, DOCX, XLSX, and PPTX can also be inspected.

Saving & restoring

  • The project automatically saves locally as changes are made.
  • The latest local project automatically restores when the page opens again.
  • Save exports or updates a workflow file.
  • Load imports a saved workflow file.
  • Embedded images and editable file contents are preserved in project data.

Menus & shortcuts

  • Right-click uses project-specific menus where available.
  • Normal browser context menus remain available inside editable text fields.
  • Esc closes image previews, file viewers, archive viewers, and this Features window.
  • Clear removes all current canvas content.
